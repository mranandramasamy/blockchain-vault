# blockchain-vault
A simple password vault based on core blockchain technique

Below is the flow diagram followed.

```mermaid
flowchart TD
    Start([Start Program]) --> Init

    subgraph Init [1. Application Initialization - Main.initiate]
        A[/Prompt: Enter Master Password/] --> B[SHA-256 Hash the Password]
        B --> C[Base64 Encode the Hash]
        C --> D[Initialize Fernet Cipher Suite]
        D --> E[Set Empty Block List & last_block = 0]
    end

    E --> InputLoop

    subgraph InputLoop [2. Main Execution Loop - Main.run]
        F[/Prompt: Enter Data or 'X'/] --> G{Is Data == 'X'?}
        G -- Yes --> H[Print All Blocks]
        H --> End([Exit Program])
        G -- No --> I[Pass Data to enc_payload]
    end

    I --> Encrypt

    subgraph Encrypt [3. Client-Side Encryption - Main.enc_payload]
        J[Fernet Encrypts Data to Bytes] --> K[Generate 16-char Random IV Prefix]
        K --> L[Combine: Random Prefix + Fernet String]
        L --> M[Return Encrypted Bundle]
    end

    M --> Mining

    subgraph Mining [4. Block Creation & Mining - Block.make_hash]
        N[Create New Block Object<br/>Assign Index, Timestamp, Prev_Hash] --> O[Base64 Encode the Encrypted Bundle]
        O --> P[Set Nonce = 0]
        
        P --> Q[Format Block String:<br/>index + time + data + prev_hash + nonce]
        Q --> R[Calculate SHA-256 Hash of String]
        
        R --> S{Does Hash start<br/>with '0' * prefix0s?}
        S -- No --> T[Nonce += 1]
        T --> Q
        
        S -- Yes --> U[Mining Complete!<br/>Save valid Hash to Block]
    end

    U --> Storage

    subgraph Storage [5. Chain Update - Main.add_a_block]
        V[Append Block to self.blocks list] --> W[Update self.last_block = block.hash]
        W --> |Loop back for next entry| F
    end
```

Note: this mermaid script is generated by Gemini based on the code implementation
